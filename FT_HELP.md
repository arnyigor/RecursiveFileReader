# FT Tool (File Tokenizer)

Утилита на Python для упаковки файлов или целых папок в один компактный текстовый токен (base64) и их последующей распаковки. Это удобно для передачи данных через текстовые сообщения, чаты или вставки в инструменты вроде Figma.

## 🚀 Быстрый старт

Так как у вас уже есть папка `.venv`, сначала нужно активировать виртуальное окружение, чтобы использовать Python из него.

### 1. Активация окружения

**Для Windows:**
```bash
.venv\Scripts\activate
```

**Для Linux / macOS:**
```bash
source .venv/bin/activate
```

---

## 📦 Использование

Скрипт поддерживает две основные команды: `pack` (упаковать) и `unpack` (распаковать).

### Упаковка (Pack)
Превращает файл или папку в длинную строку текста и сохраняет её в `.ft.txt`.

**Синтаксис:**
```bash
python ft.py pack FigmaOutput.md
```

**Примеры:**
*   **Упаковать папку `my_project`** (создаст файл `my_project.ft.txt` в текущей папке):
    ```bash
    python ft.py pack ./my_project
    ```
*   **Упаковать файл `data.zip` в конкретный файл `payload.txt`**:
    ```bash
    python ft.py pack data.zip payload.txt
    ```

> [!TIP]
> После упаковки скрипт автоматически попытается скопировать токен в ваш **буфер обмена**.

---

### Распаковка (Unpack)
Извлекает оригинальные файлы из текстового токена.

**Синтаксис:**
```bash
python ft.py unpack FigmaInput.txt
```

**Скрипт умеет брать данные тремя способами (в порядке приоритета):**
1.  Из файла, указанного в аргументах.
2.  Из вашего **буфера обмена** (если вы скопировали токен).
3.  Из **ручного ввода** в терминале (если ничего не найдено).

**Примеры:**
*   **Распаковать из буфера обмена** (просто скопируйте токен и запустите):
    ```bash
    python ft.py unpack
    ```
*   **Распаковать из файла `payload.txt` в папку `restored_files`**:
    ```bash
    python ft.py unpack payload.txt ./restored_files
    ```
*   **Распаковать из файла в текущую папку**:
    ```bash
    python ft.py unpack payload.txt
    ```

## 🛠 Технические особенности

*   **Формат архива:** Используется сжатие `tar.xz` для максимальной экономии места.
*   **Безопасность:** Каждый токен содержит SHA256-хеш содержимого. Если при передаче текста будет потерян хотя бы один символ, скрипт выдаст ошибку `Контрольная сумма не совпадает`.
*   **Зависимости:** Скрипт использует только стандартную библиотеку Python, поэтому дополнительных `pip install` не требуется.

## 📋 Справочник команд

| Команда | Аргумент 1 | Аргумент 2 | Описание |
| :--- | :--- | :--- | :--- |
| `pack` | `source` | `output.txt` (опц.) | Упаковать объект в текст |
| `unpack` | `input.txt` (опц.) | `out_dir` (опц.) | Распаковать текст в файлы |

---

### ⚠️ Возможные проблемы

*   **Ошибка "Буфер недоступен":** На некоторых Linux-системах для работы с буфером обмена могут потребоваться утилиты `xclip`, `xsel` или `wl-copy`.
*   **Ошибка "Пакет поврежден":** Убедитесь, что при копировании токена вы не захватили лишние пробелы или переносы строк, и что текст не был обрезан мессенджером.
